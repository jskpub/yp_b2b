## 화면 1: 나만의 AI 홈화면

(홈 탭 - 영풍문고 '나만의 AI' 섹션)

당신은 영풍문고 서비스 내에서 사용되는 모바일 웹 UI를 설계하는 디자이너입니다. KRDS 디자인 시스템과 모바일 웹표준을 준수하며 다음 요구사항에 따라 UI를 만들어주세요.

**페이지 명칭**: 나만의 AI 홈화면
**위치**: 홈 탭 내 메인 섹션
**화면 크기**: 375px (모바일 기준)

**필수 요소**:
1. 상단 헤더: 뒤로가기(<) 아이콘, '나만의 AI' 제목
2. 원형 아이콘 메뉴 (가로 배열, 4개): "오늘 날씨엔", "베스트 Pick!", "행사 AI Pick!", 네 번째 항목 1개 (아이콘 + 하단 라벨 텍스트)
3. AI 배너 영역: "AI와 대화를 통해 지금 읽고 싶은 도서 바로 Pick!" 문구 + 우측 화살표(») 아이콘, 클릭 시 AI 채팅화면(화면 2)으로 이동. 배너 우측 하단 또는 근처에 AI 캐릭터 아이콘 배치(사용자의 시선을 배너로 유도하는 느낌)
4. "나의 관심 영역" 섹션: 책 카드 3개 (가로 배열 또는 스크롤)
5. "요즘 인기도서" 섹션: 책 카드 3개 (가로 배열 또는 스크롤)
   - 각 카드는 책 표지 이미지 중심의 심플한 썸네일
6. 하단 네비게이션: 5개 탭 아이콘, 가운데 'HOME' 탭 강조 표시

**디자인 가이드라인**:
- 여백: 12px 좌우 패딩 (모바일)
- 카드 간격: 16px (md spacing)
- 배너는 시각적으로 가장 강조되는 영역으로 Primary 컬러 배경 활용
- 모든 상호작용 요소는 44×44px 이상의 터치 영역 확보

**접근성**:
- 모든 이미지에 의미있는 alt text 제공
- 버튼과 링크는 명확한 포커스 상태 표시 (outline: 2px Primary 500)
- 색상 대비율 4.5:1 이상 준수

## 화면 2: AI 채팅 시작화면 (키워드 요청)

(홈화면 배너 클릭 직후 진입하는 채팅 초기 상태 — 아직 사용자 입력 전)

당신은 영풍문고 서비스 내에서 사용되는 모바일 웹 UI를 설계하는 디자이너입니다. KRDS 디자인 시스템과 모바일 웹표준을 준수하며 다음 요구사항에 따라 UI를 만들어주세요.

**페이지 명칭**: AI 채팅 시작화면
**위치**: 홈화면(화면 1) 배너 클릭 시 진입
**화면 크기**: 375px (모바일 기준)

**필수 요소**:
1. 상단 헤더: 뒤로가기 버튼, '도서 추천' 제목
2. AI 첫 메시지(왼쪽 정렬, 채팅 시작 시 자동 노출): "지금 읽고 싶은 도서와 관련된 키워드 3개 정도 이야기해주세요" — 특정 책을 찾는 경우와 불특정 조건(장르·분위기·주인공 특징 등)으로 찾는 경우 모두 가능함을 보조 설명 텍스트로 안내
3. 입력 유도 예시 칩(placeholder 하단 노출, 탭하면 입력창에 자동 삽입): "#추리" "#반전" "#여자주인공" 같은 예시 태그 3~4개 — 사용자가 어떤 식으로 입력하면 되는지 직관적으로 보여주는 역할
4. 입력 필드 영역: 텍스트 입력박스(높이 44px 이상) + 전송 버튼
5. 빈 화면 하단에 이전 대화 기록이 없는 최초 진입 상태임을 표현 (스크롤 영역 최소화, 입력 유도에 초점)

**디자인 가이드라인**:
- 채팅 배경: White
- AI 메시지 배경: Neutral 100, 좌측 정렬, 모서리 8px
- 예시 칩: Neutral 200 배경 또는 Secondary 색상, 8px 패딩, pill 형태
- 입력 필드 보더: Neutral 300, 1px (포커스 시 2px Primary 500)
- 메시지 여백: 위/아래 8px, 좌우 12px

**접근성**:
- AI 메시지는 ARIA live region으로 선언 (aria-live="polite")
- 입력 필드에 명확한 label 제공 (aria-label="메시지 입력")
- 예시 칩은 버튼 요소로 구현, 명확한 포커스 상태 표시
- 키보드로 메시지 전송 가능 (Enter 키 또는 전송 버튼)

## 화면 3: AI 대화 진행 & 추천 도서 노출 화면

(사용자가 키워드를 입력한 후 AI가 도서를 추천하는 대화 흐름 — 해시태그 재검색·리뷰 요약 등 보조 기능 포함)

당신은 영풍문고 서비스 내에서 사용되는 모바일 웹 UI를 설계하는 디자이너입니다. KRDS 디자인 시스템과 모바일 웹표준을 준수하며 다음 요구사항에 따라 UI를 만들어주세요.

**페이지 명칭**: AI 대화 및 도서 추천 진행 화면
**위치**: 화면 2에서 사용자가 키워드를 입력해 전송한 직후
**화면 크기**: 375px (모바일 기준)

**필수 요소**:
1. 상단 헤더: 뒤로가기 버튼, '도서 추천' 제목 (화면 2와 동일 유지)
2. 사용자 메시지(오른쪽 정렬): 입력한 키워드를 번호 매김 리스트 형태로 표시 (예: "1. 추리\n2. 반전\n3. 주인공이 여자") — 여러 조건을 한 번에 입력했을 때 가독성 있게 구조화
3. AI 응답 메시지(왼쪽 정렬): "책을 찾아드릴게요" 안내 후 이어서 "추천된 도서는 OOO입니다. 마음에 드는 도서가 있으면 선택해주세요~"
4. 추천 도서 카드 (채팅 말풍선 내 인라인 카드, 가로 스크롤 가능, 1개 이상)
   - 책 표지 썸네일, 책 제목, **저자명**(추가), 짧은 줄거리 요약
   - "자세히 보기" 버튼 → 클릭 시 도서 상세화면(화면 5)으로 이동
5. 조건 재검색용 해시태그 칩: 추천 카드 하단에 사용자가 입력한 키워드 기반 칩 노출 (예: "#추리" "#반전" "#여자주인공"), 칩을 탭하면 해당 조건이 대화에 반영되어 추천 목록이 갱신됨 — 조건을 좁히거나 다른 조건으로 바꿀 때 사용
6. 후속 질문 유도 칩: "리뷰 요약해줘" 버튼 — 탭 시 AI가 아래 형태의 **구조화된 리뷰 요약 카드**로 응답
   - 별점 표시 (예: "★★★★☆ 4.0")
   - 독자 반응 키워드 bullet 태그 2~3개 (예: "반전", "통쾌")
   - 한 줄 총평 문장 (예: "전반적으로 반전이 통쾌하다는 평입니다.")
7. 보조 선택지 버튼(칩 형태): "다른 도서 추천받고 싶어요" / "키워드 다시 입력할래요"
8. 하단 고정 입력 필드 영역: 텍스트 입력박스(높이 44px 이상) + 전송 버튼

**디자인 가이드라인**:
- 채팅 배경: White
- AI 메시지/추천 카드 배경: Neutral 100, 좌측 정렬
- 사용자 메시지 배경: Primary 500, 우측 정렬, 흰 텍스트
- 메시지 여백: 위/아래 8px, 좌우 12px
- 추천 카드: 보더 1px Neutral 200, 모서리 8px, 내부 패딩 12px
- 리뷰 요약 카드: 추천 카드와 시각적으로 구분되도록 별점은 아이콘+숫자 병기, 키워드 bullet은 Secondary 색상 pill로 표시
- 해시태그 칩 / 후속 질문 칩: Neutral 200 배경 또는 Secondary 색상, 8px 패딩, pill 형태
- 입력 필드 보더: Neutral 300, 1px

**접근성**:
- 메시지는 ARIA live region으로 선언 (aria-live="polite")
- 입력 필드에 명확한 label 제공 (aria-label="메시지 입력")
- 해시태그 칩·후속 질문 칩은 명확한 포커스 상태와 선택 상태(aria-pressed 등) 표시
- 별점은 색상뿐 아니라 숫자("4.0")와 텍스트로도 값 제공 (색상/별 아이콘만으로 정보 전달 금지)
- 키보드로 메시지 전송 가능 (Enter 키 또는 버튼)

## 화면 4: 추천 도서 선택 화면

(추천 목록에서 도서를 선택하는 시점 — 선택/미선택 두 가지 분기 상태 표현)

당신은 영풍문고 서비스 내에서 사용되는 모바일 웹 UI를 설계하는 디자이너입니다. KRDS 디자인 시스템과 모바일 웹표준을 준수하며 다음 요구사항에 따라 UI를 만들어주세요.

**페이지 명칭**: 추천 도서 선택 화면
**위치**: 화면 3의 추천 도서 카드 목록에서 사용자가 하나를 탭하는 시점
**화면 크기**: 375px (모바일 기준)

**필수 요소**:
1. 상단 헤더, 채팅 대화 흐름은 화면 3과 동일하게 이어짐 (스크롤 시 상단 대화 내역 유지)
2. 추천 도서 카드 목록(가로 스크롤, 2개 이상) — 사용자가 카드를 탭했을 때의 상태 변화를 명확히 표현
3. 대화 분기 처리 (2가지 상태를 화면에 함께 또는 대표 상태로 표현)
   - **Case A — 미선택**: 추천 목록에서 도서를 선택하지 않고 계속 대화하는 경우. 안내 가이드 메시지 노출("다른 키워드로 다시 찾아드릴까요?" 등), "다른 도서 추천받기" / "키워드 다시 입력하기" 버튼 유지
   - **Case B — 선택**: 사용자가 카드를 탭하면 해당 카드가 선택 상태로 전환 (보더 Primary 500 2px 강조 + 체크 아이콘 등 비색상 단서 병행), "자세히 보기" 버튼이 강조되어 도서 상세화면(화면 5)으로 이동 가능
4. 선택된 카드에는 선택 시각(타임스탬프)이나 "선택됨" 라벨 등 명확한 선택 피드백 텍스트 제공

**디자인 가이드라인**:
- 카드 기본 상태: 보더 1px Neutral 200, 모서리 8px
- 카드 선택 상태: 보더 2px Primary 500, 우측 상단 체크 아이콘(Primary 500) 배치
- 선택 전환 애니메이션: 150~200ms ease-out
- 나머지 채팅/입력 영역 스타일은 화면 3과 동일하게 유지 (일관성)

**접근성**:
- 선택된 카드는 aria-pressed="true" 또는 role="button" + aria-selected 속성으로 선택 상태를 스크린리더에 전달
- 선택 상태는 색상뿐 아니라 아이콘·텍스트 라벨로도 함께 표시 (색상만으로 정보 전달 금지)
- 카드와 버튼 모두 명확한 포커스 상태 표시 (outline 2px Primary 500)

## 화면 5: 도서 상세화면

(추천 목록에서 선택한 도서의 상세 정보 및 구매 — AI 개인화 요소 포함)

당신은 영풍문고 서비스 내에서 사용되는 모바일 웹 UI를 설계하는 디자이너입니다. KRDS 디자인 시스템과 모바일 웹표준을 준수하며 다음 요구사항에 따라 UI를 만들어주세요.

**페이지 명칭**: 도서 상세화면
**위치**: 화면 4에서 "자세히 보기" 선택 시 진입
**화면 크기**: 375px (모바일 기준)

**필수 요소**:
1. 상단 헤더: 뒤로가기, 제목 영역
2. 책 표지 이미지: 최소 240×340px (반응형)
3. 기본 정보 섹션: 제목, 저자, 출판사, 금액 (라벨 + 값 형태)
4. "AI 요약" 섹션: AI가 생성한 책 소개/줄거리 요약 텍스트 박스
5. "선호 매칭" 섹션: 채팅에서 사용자가 선택한 키워드를 기반으로 한 매칭 비율을 게이지 바(%)로 표시 (예: 80%)
6. "다른 사람과의 취향 매칭" 섹션: 사용자의 관심 영역·구매 이력 등 데이터 기반 협업 필터링 결과를 게이지 바(%)와 문구로 표시 (예: "이 책은 OO님과 __%만큼 취향이 일치해요")
7. 하단 고정 버튼 영역: "장바구니" 버튼(좌측, Secondary) + "구매하기" 버튼(우측, Primary, 클릭 시 화면 6 구매화면으로 이동), 각 버튼 높이 48px 이상

**디자인 가이드라인**:
- 배경: White
- 섹션 간 구분: Neutral 200 보더 또는 여백으로 시각적 구획
- 섹션 패딩: 16px 좌우, 16px 위아래
- 게이지 바(매칭 비율)는 시각적 요소(막대/도넛 등)와 함께 반드시 텍스트(%)로도 값 표시

## 화면 6: 구매(주문/결제) 화면

(도서 상세화면에서 "구매하기" 선택 시 진입 — 추천받은 도서를 바로 구매하는 플로우의 마지막 단계)

당신은 영풍문고 서비스 내에서 사용되는 모바일 웹 UI를 설계하는 디자이너입니다. KRDS 디자인 시스템과 모바일 웹표준을 준수하며 다음 요구사항에 따라 UI를 만들어주세요.

**페이지 명칭**: 구매(주문/결제) 화면
**위치**: 화면 5의 "구매하기" 버튼 선택 시 진입
**화면 크기**: 375px (모바일 기준)

**필수 요소**:
1. 상단 헤더: 뒤로가기, '주문/결제' 제목
2. 주문 상품 요약 카드: 책 표지 썸네일(소형, 예: 60×85px) + 책 제목 + 가격 + 수량(기본 1, 증감 컨트롤 선택 제공)
3. 배송지 정보 섹션: 기본 배송지(수령인, 주소, 연락처) 표시 + "변경" 버튼
4. 결제 수단 선택 섹션: 라디오 버튼 리스트 (카드결제, 간편결제 등 2개 이상)
