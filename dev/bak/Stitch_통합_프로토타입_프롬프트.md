# Stitch용 통합 프로토타입 프롬프트

> 아래 내용은 `프로토타입_화면별_프롬프트.md`(6화면 버전), `사용자플로우.md`, `KRDS-Design-System-Guide.md`, `mobile-design-coding-standards.md`, `모바일웹표준.md`, `채팅화면_참고자료.jpg`의 핵심 내용을 종합해 Stitch에 그대로 붙여넣을 수 있도록 정리한 프롬프트입니다.
>
> **컬러는 `디자인시스템.svg` 파일을 별도로 첨부해 전달할 예정이라 이 프롬프트에는 색상 값을 포함하지 않았습니다.** Stitch에 프롬프트와 함께 해당 SVG를 첨부해, 텍스트/버튼/카드/배너 등에 적용할 색상은 그 파일을 기준으로 반영해달라고 안내해주세요.

```
[프로젝트 개요]
영풍문고 모바일 웹 서비스의 신규 기능 '나만의 AI'의 6단계 프로토타입을 제작해줘.
AI와 대화하며 도서를 추천받고, 추천 도서 상세를 확인한 뒤 구매까지 이어지는 플로우야.
컬러는 별도로 첨부한 디자인시스템.svg 파일의 팔레트를 그대로 적용해줘 (아래 프롬프트에는 색상 값을 명시하지 않았어).

전체 사용자 플로우 (화면 1~6과 1:1 대응):
1. 사용자가 '나만의 AI' 홈화면으로 진입
2. 'AI와 대화하여 나만의 읽고싶은 도서 Pick' 배너 클릭 → AI 채팅화면 진입 (키워드 요청)
3. AI와 대화를 통해 읽고 싶은 책 추천받음 (대화 진행 + 추천 카드 노출)
4. AI가 추천한 도서 목록 중 마음에 드는 도서 선택
5. 선택한 도서의 상세화면으로 진입
6. 추천받은 도서를 바로 구매 (주문/결제)

[공통 디자인 시스템 — KRDS(대한민국 정부 디자인 시스템) 기반, 반드시 전 화면 통일 적용]

화면 크기: 375px 모바일 기준, 단일 컬럼 세로 스크롤

타이포그래피 (폰트: Pretendard GOV, 없으면 시스템 산세리프 폴백):
- H1 32px/Bold, H2 26px/Bold, H3 22px/SemiBold, H4 19px/SemiBold
- 본문(Body Large) 17px/Regular, line-height 1.5 (본문 기본 크기를 크게 잡아 노안·저시력 사용자 배려)
- Body Medium 15px, Body Small 13px, Caption 12px(최소, 이보다 작은 텍스트 금지)
- 한글 자간은 기본 0 (자간 좁히지 않음)

간격(8px 기반): xs 4px / sm 8px / md 16px / lg 24px / xl 32px
- 모바일 콘텐츠 좌우 패딩: 16px (또는 화면별 12px 지정 시 그 값 우선)
- 카드 간격: 16px, 카드 내부 패딩: 16~24px

컴포넌트 규칙 (색상 제외, 구조만):
- 버튼: 주요 액션용 1종 + 보조 액션용 1종, 기본 높이 44px 이상, Large 52px, 모서리 radius 6~8px
- 카드: 보더 1px, radius 8px, 옅은 그림자
- 입력 필드: 높이 44px 이상, 보더 1px(포커스 시 2px로 강조), radius 6px
- 하단 네비게이션 바: 5개 탭, safe-area 고려
- 모든 인터랙티브 요소(버튼/링크/칩/카드) 터치 영역 44×44px 이상 확보
- 포커스 상태: outline 2px solid + outline-offset 2px (제거 금지)

접근성(WCAG 2.1 AA 준수):
- 텍스트 대비 4.5:1 이상, 큰 텍스트/UI 요소 3:1 이상
- 색상만으로 정보 전달 금지 (아이콘·텍스트 등 비색상 단서 병행) — 특히 매칭 게이지, 선택 카드, 별점 표시에 적용
- 모든 이미지에 의미 있는 alt 텍스트, 아이콘 전용 버튼에 aria-label
- safe-area(노치, 홈 인디케이터) 고려한 하단 고정 영역 여백

---

[화면 1] 나만의 AI 홈화면
위치: 홈 탭 내 메인 섹션 / 375px 모바일

구성 요소:
1. 상단 헤더: 뒤로가기(<) 아이콘 + '나만의 AI' 타이틀
2. 원형 아이콘 메뉴 4개(가로 배열, 아이콘+하단 라벨): "오늘 날씨엔", "베스트 Pick!", "행사 AI Pick!", 그리고 4번째 항목 1개
3. AI 배너: "AI와 대화를 통해 지금 읽고 싶은 도서 바로 Pick!" 문구 + 우측 화살표(») 아이콘, 배너 근처에 AI 캐릭터 아이콘 배치. 이 배너는 화면에서 가장 시각적으로 강조되어야 하며 클릭 시 화면 2로 이동
4. "나의 관심 영역" 섹션: 책 표지 중심 카드 3개(가로 스크롤)
5. "요즘 인기도서" 섹션: 책 표지 중심 카드 3개(가로 스크롤)
6. 하단 네비게이션 5개 탭, 가운데 'HOME' 탭 활성 강조

레이아웃 여백: 좌우 패딩 12px, 카드 간격 16px

---

[화면 2] AI 채팅 시작화면 (키워드 요청)
위치: 화면 1의 AI 배너 클릭 시 진입 / 375px 모바일 / 대화 이전의 초기 상태

구성 요소:
1. 상단 헤더: 뒤로가기 + '도서 추천' 타이틀
2. AI 첫 메시지(좌측 정렬): "지금 읽고 싶은 도서와 관련된 키워드 3개 정도 이야기해주세요" — 특정 책을 찾을 때와 불특정 조건(장르·분위기·주인공 특징 등)으로 찾을 때 모두 가능함을 보조 설명
3. 입력 유도 예시 칩(placeholder 하단, 탭하면 입력창에 자동 삽입): "#추리" "#반전" "#여자주인공" 등 예시 태그 3~4개
4. 하단 고정 입력 영역: 텍스트 입력 필드(높이 44px 이상) + 전송 버튼
5. 아직 이전 대화 기록이 없는 최초 진입 상태 (입력 유도에 초점)

디자인: AI 메시지 좌측 정렬, 예시 칩은 pill 형태, 입력 필드는 기본 보더 스타일 유지

---

[화면 3] AI 대화 진행 & 추천 도서 노출 화면
위치: 화면 2에서 사용자가 키워드를 입력해 전송한 직후 / 375px 모바일

구성 요소:
1. 상단 헤더는 화면 2와 동일 유지
2. 사용자 메시지(우측 정렬): 입력한 키워드를 번호 매김 리스트로 표시 (예: "1. 추리 / 2. 반전 / 3. 주인공이 여자")
3. AI 응답 메시지(좌측 정렬): "책을 찾아드릴게요" → "추천된 도서는 OOO입니다. 마음에 드는 도서가 있으면 선택해주세요~"
4. 추천 도서 카드(AI 말풍선 안에 인라인, 가로 스크롤 가능, 1개 이상): 책 표지 썸네일 + 도서명 + 저자명 + 짧은 줄거리 요약 + "자세히 보기" 버튼(클릭 시 화면 5로 이동)
5. 추천 카드 하단 재검색용 해시태그 칩: 사용자가 입력한 키워드 기반 칩(예: "#추리" "#반전" "#여자주인공"), 탭하면 조건이 반영되어 추천 목록 갱신
6. 후속 질문 유도 칩 "리뷰 요약해줘" → 탭 시 AI가 구조화된 리뷰 요약 카드로 응답: 별점("★★★★☆ 4.0") + 감성 키워드 bullet 태그(예: "반전", "통쾌") + 한 줄 총평("전반적으로 반전이 통쾌하다는 평입니다.")
7. 보조 선택 칩(pill 형태): "다른 도서 추천받고 싶어요" / "키워드 다시 입력할래요"
8. 하단 고정 입력 영역: 텍스트 입력 필드 + 전송 버튼

디자인: 메시지 여백 상하 8px/좌우 12px, 추천 카드 보더 1px/radius 8px/내부 패딩 12px, 리뷰 요약 카드는 별점 아이콘+숫자 병기 및 키워드 pill로 추천 카드와 시각적으로 구분(레이아웃 기준, 색상은 SVG 참조)

---

[화면 4] 추천 도서 선택 화면
위치: 화면 3의 추천 카드 목록에서 사용자가 하나를 탭하는 시점 / 375px 모바일

구성 요소:
1. 상단 헤더 및 채팅 흐름은 화면 3과 동일하게 이어짐(스크롤 시 대화 내역 유지)
2. 추천 도서 카드 목록(가로 스크롤, 2개 이상)
3. 대화 분기 상태 2가지:
   - Case A(미선택): 안내 문구("다른 키워드로 다시 찾아드릴까요?") + "다른 도서 추천받기"/"키워드 다시 입력하기" 버튼 유지
   - Case B(선택): 탭한 카드가 선택 상태로 전환 — 보더를 굵게 강조 + 체크 아이콘(비색상 단서) 병행, "자세히 보기" 버튼 강조 표시
4. 선택된 카드에 "선택됨" 라벨 등 명확한 선택 피드백 제공

디자인: 카드 기본 보더 1px/radius 8px, 선택 시 보더 2px로 강조 + 우측 상단 체크 아이콘, 전환 애니메이션 150~200ms ease-out (강조 색상은 SVG 참조)

---

[화면 5] 도서 상세화면
위치: 화면 4에서 "자세히 보기" 선택 시 진입 / 375px 모바일

구성 요소:
1. 상단 헤더: 뒤로가기 + 타이틀 영역
2. 책 표지 이미지: 최소 240×340px
3. 기본 정보: 제목, 저자, 출판사, 가격(라벨+값 형태, "원" 단위 텍스트 포함)
4. "AI 요약" 섹션: AI가 생성한 책 소개/줄거리 요약 텍스트 박스
5. "선호 매칭" 섹션: 채팅에서 선택한 키워드 기반 매칭률을 게이지 바(%)로 표시 (예: 80%) — 시각 요소+숫자 동시 표기
6. "다른 사람과의 취향 매칭" 섹션: 협업 필터링 기반 매칭률을 게이지 바(%)+문구로 표시 (예: "이 책은 OO님과 __%만큼 취향이 일치해요")
7. 하단 고정 버튼 바: "장바구니"(좌측, 보조 버튼) + "구매하기"(우측, 주요 버튼, 클릭 시 화면 6으로 이동), 각 버튼 높이 48px 이상, 버튼 사이 간격 8px, safe-area 고려

디자인: 섹션 간 보더 또는 여백으로 구획, 섹션 패딩 16px

---

[화면 6] 구매(주문/결제) 화면
위치: 화면 5의 "구매하기" 버튼 선택 시 진입 / 375px 모바일

구성 요소:
1. 상단 헤더: 뒤로가기 + '주문/결제' 타이틀
2. 주문 상품 요약 카드: 책 표지 썸네일(소형, 60×85px) + 책 제목 + 가격 + 수량
3. 배송지 정보 섹션: 기본 배송지(수령인/주소/연락처) + "변경" 버튼
4. 결제 수단 선택 섹션: 라디오 버튼 리스트(카드결제, 간편결제 등 2개 이상)
5. 결제 금액 요약: 상품 금액, 배송비, 총 결제 금액(굵게 강조)
6. 하단 고정 버튼: "결제하기"(주요 버튼, full-width, 높이 52px 이상)
7. 구매 완료 상태(선택): 체크 아이콘 + "구매가 완료되었습니다" + 주문번호 + "홈으로"/"주문 내역 보기" 버튼

디자인: 섹션 간 보더 또는 여백 구획, 라디오 선택 시 보더 강조+채움 표시

---

[요청]
위 6개 화면을 사용자 플로우 순서대로 하나의 연결된 프로토타입으로 만들어줘. 각 화면 간 전환 인터랙션(배너 클릭 → 채팅 시작 → 대화 진행 → 도서 선택 → 상세 → 구매)도 함께 연결해줘. 컬러는 함께 첨부하는 디자인시스템.svg를 기준으로 적용해줘.
```
