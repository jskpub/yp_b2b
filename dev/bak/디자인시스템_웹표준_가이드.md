## 개요

### 목적
- 서비스 전반의 화면을 디자인·개발할 때 참조할 **단일 기준**을 제공합니다.
- KRDS의 접근성·타이포그래피 원칙은 유지하면서, 실제 서비스(`ypbook.css`)에서 쓰이는 컬러와 정합성을 맞춰 디자인 산출물이 실서비스 톤앤매너에서 벗어나지 않도록 합니다.

### 대상
- **디자이너:** 화면 설계 시 컬러·타이포·간격 토큰 참조
- **개발자:** CSS 변수, 컴포넌트 마크업/스타일 구현 기준
- **PM:** 기획·검수 단계의 체크리스트

### 적용 범위
- 모바일 우선(Mobile First), 375px을 기본 설계 기준으로 함
- 태블릿/데스크톱은 [레이아웃 & 반응형](#레이아웃--반응형)의 브레이크포인트를 따름

## 기본 원칙

KRDS 가이드의 4대 원칙을 이 프로젝트에도 동일하게 적용합니다.

### 1. 단순성과 명확성
- 채팅형 UI 특성상 정보가 순차적으로 쌓이므로, 불필요한 장식보다 **대화 흐름의 가독성**을 우선합니다.
- AI 메시지·사용자 메시지·추천 카드·칩(chip) 등 컴포넌트 간 시각적 위계를 명확히 구분합니다.

### 2. 포용성 (Inclusive by default)
- 노안·저시력 사용자를 우선 고려해 본문 기본 크기를 크게 잡습니다 (17px, [타이포그래피](#타이포그래피) 참조).
- 매칭률·별점·선택 상태 등은 **색상만으로 전달하지 않고** 숫자/텍스트/아이콘을 병행합니다.

### 3. 반응형 설계
- 모바일 우선(Mobile First). 375px 기준으로 설계하되, 태블릿/데스크톱 대응 규칙을 함께 정의합니다.

### 4. 한글 최적화
- 한글 가독성을 고려한 행간(기본 1.5 이상)과 자간(기본 0).
- Pretendard GOV로 한글 웹폰트를 통일합니다.

## 타이포그래피

### 폰트 패밀리 — Pretendard GOV

이 프로젝트는 **Pretendard GOV**를 기본 서체로 사용합니다. `ypbook.css`는 현재 `body, input, select, textarea, button { font-family: 'Pretendard', sans-serif; }`로 일반 Pretendard를 쓰고 있는데, 이 문서 적용 시 **Pretendard GOV로 교체**하는 것을 표준으로 합니다 (공공/신뢰 톤이 필요한 AI 안내 문구, 결제 화면 등에서 가독성 이점이 있음).

#### CSS 적용
```html
<link rel="stylesheet" as="style" crossorigin
  href="https://cdnjs.cloudflare.com/ajax/libs/pretendard-gov/1.3.9/variable/pretendardvariable-gov.min.css" />
```

```css
:root {
  --font-family-base:
    'Pretendard GOV', 'PretendardGOVVariable',
    -apple-system, BlinkMacSystemFont,
    'Apple SD Gothic Neo', 'Malgun Gothic',
    system-ui, Roboto, sans-serif;
}

body, input, select, textarea, button {
  font-family: var(--font-family-base);
}
```

> 웨이트는 일반적으로 **400 / 500 / 600 / 700** 네 가지면 UI 전체(본문, 라벨, 소제목, 강조 텍스트, 버튼)를 충분히 커버합니다. 상세 웨이트 목록과 라이선스는 [KRDS-Design-System-Guide.md](./KRDS-Design-System-Guide.md#타이포그래피)를 참고하세요.

### 폰트 크기 스케일

노안·저시력 사용자를 우선 고려해 **본문 기본 크기를 17px**로 잡습니다 (KRDS 기준과 동일).

| 레벨 | 크기 | 웨이트 | 행간 | 사용처 예시 |
|------|------|--------|------|------|
| Heading 1 | 32px / 2rem | 700 | 1.35 | 페이지 타이틀 (모바일에서는 H1 대신 헤더 타이틀로 대체 가능) |
| Heading 2 | 26px / 1.625rem | 700 | 1.4 | "구매가 완료되었습니다" 등 결과 안내 |
| Heading 3 | 22px / 1.375rem | 600 | 1.4 | 섹션 제목 ("AI 요약", "선호 매칭") |
| Heading 4 | 19px / 1.1875rem | 600 | 1.45 | 도서 상세 제목, 카드 타이틀, 총 결제 금액 |
| Body Large | 17px / 1.0625rem | 400 | 1.5 | **본문 기본**, AI/사용자 채팅 메시지 |
| Body Medium | 15px / 0.9375rem | 400 (버튼은 600) | 1.5 | 버튼 라벨, 입력 필드, 카드 부가 정보 |
| Body Small | 13px / 0.8125rem | 400 | 1.5 | 헬퍼 텍스트, 해시태그 칩, 타임스탬프 |
| Caption | 12px / 0.75rem | 400 | 1.4 | 최소 크기 — 저작권, 각주 (이보다 작게 사용 금지) |

```css
:root {
  --font-size-h2: 1.625rem;       /* 26px */
  --font-size-h3: 1.375rem;       /* 22px */
  --font-size-h4: 1.1875rem;      /* 19px */
  --font-size-body-lg: 1.0625rem; /* 17px — 채팅 메시지, 본문 기본 */
  --font-size-body-md: 0.9375rem; /* 15px — 버튼, 입력 필드 */
  --font-size-body-sm: 0.8125rem; /* 13px — 헬퍼 텍스트, 칩 */
  --font-size-caption: 0.75rem;   /* 12px — 최소 크기 */

  --line-height-heading: 1.4;
  --line-height-body: 1.5;

  --letter-spacing-default: 0; /* 한글 자간은 기본 0, 임의 조정 금지 */
}
```

> 🚫 **12px 미만 사용 금지.** 행간은 본문 기준 1.5 이상, 한글 본문에 음수 자간을 적용하지 않습니다. 상세 근거는 [KRDS-Design-System-Guide.md](./KRDS-Design-System-Guide.md#타이포그래피)의 행간/자간 규칙을 따릅니다.

## 컬러 시스템

### 원칙
KRDS는 정부 블루를 축으로 하지만, 이 프로젝트는 **`ypbook.css`에 이미 정의된 실서비스 컬러 변수**를 그대로 가져와 사용합니다. 새 색상을 임의로 추가하지 않고, 기존 변수에 **의미(semantic role)를 부여**하는 방식으로 디자인 시스템화합니다.

### 원본 변수 (ypbook.css `:root`, 그대로 유지)

```css
:root {
  /* warm grey — 주로 텍스트에 사용됨 */
  --white: #ffffff;
  --wgrey01: #f6f6f6;
  --wgrey02: #dadada;
  --wgrey03: #c3c2c2;
  --wgrey04: #aeaeae;
  --wgrey05: #9c9c9c;
  --wgrey06: #7e7e7e;
  --wgrey07: #595959;
  --wgrey08: #363636;
  --wgrey09: #181718;

  /* cool grey — 주로 배경/보더에 사용됨 */
  --cgrey01: #edf0f1;
  --cgrey02: #cbd2d4;
  --cgrey03: #b5bec0;
  --cgrey04: #9da6a8;
  --cgrey05: #80888a;
  --cgrey06: #686e70;
  --cgrey07: #555a5c;
  --cgrey08: #3c4142;
  --cgrey09: #1e2021;

  /* red — 브랜드 강조 스케일 */
  --red01: #ffebeb;
  --red02: #f9cdcd;
  --red03: #f5baba;
  --red04: #fd9999;
  --red05: #f87e7e;
  --red06: #f55d5d;
  --red07: #f14646;
  --red08: #ea2e2e;
  --red09: #df0000;

  /* green */
  --green: #4aaf70;
  --green01: #1f976b;

  /* etc */
  --warning: #ee293b;
  --nowdream: #be1d27;
}
```

### 시맨틱 매핑 (이 문서에서 신규 정의)

원본 변수는 그대로 두고, 용도를 명확히 하기 위한 시맨틱 토큰을 별도로 얹습니다.

```css
:root {
  /* 배경 */
  --color-canvas: var(--white);        /* 기본 배경 */
  --color-surface: var(--wgrey01);     /* 카드/섹션 약한 배경 */
  --color-surface-alt: var(--cgrey01); /* AI 메시지, 추천 카드 배경 */

  /* 텍스트 */
  --color-foreground: var(--wgrey09);      /* 기본 텍스트 (거의 검정) */
  --color-foreground-secondary: var(--wgrey07); /* 보조 텍스트 */
  --color-muted: var(--wgrey05);           /* 헬퍼 텍스트, 비활성 텍스트 */

  /* 경계선 */
  --color-border: var(--cgrey02);      /* 카드/인풋 기본 보더 (hairline) */
  --color-border-strong: var(--cgrey04); /* 강조가 필요한 보더 */

  /* 브랜드 강조(Primary) */
  --color-primary: var(--red09);       /* 주요 액션, 선택 상태, CTA */
  --color-primary-hover: var(--red08); /* 호버/눌림 */
  --color-primary-soft: var(--red01);  /* 강조 배경(연한 톤) */

  /* 시맨틱 상태 */
  --color-success: var(--green01);
  --color-warning: var(--warning);
  --color-danger: var(--red09);        /* 이 브랜드는 Primary와 Danger가 동일 Red 계열을 공유 */
  --color-danger-soft: var(--red01);
}
```

> ⚠️ **Primary와 Danger가 같은 색상 계열입니다.** `ypbook.css`에는 위험/삭제 전용 색이 따로 없고 `--red09`가 CTA·가격 강조·오류 표시에 두루 쓰입니다. 따라서 삭제/위험 액션은 **색상만으로 구분하지 말고 아이콘·문구("삭제하시겠어요?")를 반드시 함께 제공**하세요. 이는 [접근성](#접근성) 원칙("색상만으로 정보 전달 금지")과도 맞닿아 있습니다.

### 시맨틱 컬러 참조표

| 역할 | 변수 | HEX | 적용 예 |
|------|------|-----|------|
| Canvas | `--color-canvas` | #FFFFFF | 전체 배경 |
| Surface (AI 메시지/카드) | `--color-surface-alt` | #EDF0F1 | AI 채팅 말풍선, 추천 카드 배경 |
| Foreground | `--color-foreground` | #181718 | 본문, 헤딩 |
| Foreground Secondary | `--color-foreground-secondary` | #595959 | 부가 설명, 작가명 |
| Muted | `--color-muted` | #9C9C9C | placeholder, 비활성 텍스트 |
| Border | `--color-border` | #CBD2D4 | 카드/인풋 기본 보더 |
| Primary | `--color-primary` | #DF0000 | 사용자 채팅 말풍선, 선택된 카드 보더, CTA 버튼, "구매하기" |
| Primary Hover | `--color-primary-hover` | #EA2E2E | 버튼 호버/눌림 |
| Success | `--color-success` | #1F976B | 결제 완료 체크 아이콘 |
| Warning/강조 | `--color-warning` | #EE293B | 신규/인기 강조 라벨 |
| Danger | `--color-danger` | #DF0000 | 오류 메시지 (아이콘·문구 병행 필수) |

### 색상 대비율

| 조합 | 근사 대비율 | 판정 |
|------|-----------|------|
| Foreground(#181718) on Canvas(#FFFFFF) | 약 18.9:1 | AA/AAA 통과 |
| Foreground Secondary(#595959) on Canvas | 약 7:1 | AA/AAA 통과 |
| White text on Primary(#DF0000) | 약 5.1:1 | 일반 텍스트 AA 통과 (버튼 라벨 등) |
| Muted(#9C9C9C) on Canvas | 약 2.7:1 | **미달 — 본문/라벨에 사용 금지, 장식·placeholder 한정** |

> ✅ 새 조합을 추가할 때는 [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/)로 재검증하세요. `--wgrey04`~`--wgrey06`(Muted 계열)은 대비율이 낮아 **본문 텍스트나 중요 라벨에는 사용하지 않습니다.**

## 레이아웃 & 반응형

### 기준 너비
모바일 우선(Mobile First) 원칙에 따라 **375px 모바일 기준**으로 설계합니다.

| 디바이스 | 너비 | 비고 |
|---------|------|------|
| 모바일 (기준) | 375px | 좌우 패딩 12px~16px |
| 태블릿 | 768px+ | 2~3 컬럼 |
| 데스크톱 | 1024px+ | 최대 콘텐츠 폭 제한 권장 |

```css
/* 모바일 우선 */
@media (min-width: 768px)  { /* 태블릿 */ }
@media (min-width: 1024px) { /* 데스크톱 */ }
```

### 간격 (Spacing)

8px 기반 스케일 (KRDS와 동일):

```css
:root {
  --spacing-xs: 0.25rem;  /* 4px  — 아이콘-텍스트 사이 */
  --spacing-sm: 0.5rem;   /* 8px  — 메시지 상하 여백 */
  --spacing-md: 1rem;     /* 16px — 기본 간격, 카드 간격 */
  --spacing-lg: 1.5rem;   /* 24px — 컴포넌트 사이, 섹션 패딩 */
  --spacing-xl: 2rem;     /* 32px — 섹션 내부 */
}
```

### 영역별 패딩 기준

| 영역 | 패딩 |
|------|------|
| 화면 좌우 콘텐츠 영역 | 12px~16px |
| 채팅 메시지 여백 | 상하 8px, 좌우 12px |
| 카드/섹션 내부 패딩 | 16px~24px |
| 하단 고정 버튼 영역 | 좌우 12px + safe-area |

### Safe Area
구매/결제 화면처럼 하단 고정 버튼이 있는 화면은 iOS 노치·Android 홈 인디케이터를 고려합니다.

```css
.fixed-bottom-bar {
  padding-bottom: calc(12px + env(safe-area-inset-bottom));
}
```

## 컴포넌트

KRDS의 버튼/입력필드/카드/모달 기본 규격([KRDS-Design-System-Guide.md](./KRDS-Design-System-Guide.md#컴포넌트) 참조)을 기반으로, 서비스 전반에서 반복적으로 쓰이는 컴포넌트를 아래와 같이 정의합니다. 색상 값은 모두 위 [컬러 시스템](#컬러-시스템)의 시맨틱 토큰을 사용합니다.

### 버튼

| 타입 | 배경 | 텍스트 | 보더 | 용도 |
|------|------|--------|------|------|
| Primary | `--color-primary` | White | 없음 | "구매하기", "결제하기", "제출하기" |
| Secondary | `--color-surface` | `--color-foreground` | `--color-border` | "장바구니", "변경" |
| Tertiary | Transparent | `--color-primary` | 없음 | "자세히 보기" 텍스트형 버튼 |
| Disabled | `--wgrey01` | `--color-muted` | 없음 | 비활성 상태 |

```
Default : 44px height | 15px / 600 | 기본 사용
Large   : 52px height | 17px / 600 | CTA ("결제하기" 등 화면 하단 고정 버튼)
```

### 채팅 말풍선 (AI / 사용자)

AI 채팅 화면 전반에서 쓰이는 핵심 컴포넌트입니다.

| 구분 | 배경 | 텍스트 | 정렬 | 모서리 |
|------|------|--------|------|--------|

## 접근성

WCAG 2.1 Level AA를 최소 기준으로 합니다.

### 색상
- ✅ 색상만으로 정보 전달 금지 — 특히 Primary(#DF0000)가 CTA·선택·오류에 모두 쓰이므로, 상태 구분은 아이콘/텍스트/보더 두께로 보강합니다.
- ✅ 일반 텍스트 4.5:1 / 큰 텍스트·UI 컴포넌트 3:1 이상.
- ✅ `--wgrey04`~`06`, `--cgrey03`~`05` 계열은 대비가 낮아 본문/중요 라벨에 미사용.

### 채팅 UI 전용 규칙
- AI/사용자 메시지 영역: `aria-live="polite"`
- 결제 완료 등 즉시성 높은 안내: `aria-live="assertive"`
- 입력 필드: `aria-label="메시지 입력"`
- 칩·카드 선택 상태: `aria-pressed` / `aria-selected` / `role="button"`

### 폼 · 게이지 · 별점
- 매칭률/별점은 숫자·텍스트를 시각 요소와 함께 제공
- 라디오 그룹: `role="radiogroup"` + `aria-label`
- 오류 발생 시 첫 오류 필드로 포커스 자동 이동, `aria-describedby`로 오류 메시지 연결

### 키보드 · 스크린 리더
- 모든 상호작용 요소 44×44px 이상, 탭 순서 DOM 순서와 일치
- Esc로 모달 닫기, 포커스 트랩/복귀
- 스크린 리더: NVDA(Windows) + Chrome, VoiceOver(iOS/macOS) 테스트 권장

세부 ARIA 속성표·시맨틱 HTML 예시는 [KRDS-Design-System-Guide.md](./KRDS-Design-System-Guide.md#접근성-accessibility)를 그대로 따릅니다.

## 체크리스트

### 디자인
- [ ] 본문 텍스트는 17px 기준, 12px 미만 텍스트 없음
- [ ] 행간 1.5 이상, 한글 본문 자간 0
- [ ] 색상은 이 문서의 시맨틱 토큰(`--color-*`)만 사용
- [ ] Primary(#DF0000)를 CTA/선택/오류에 중복 사용할 경우 아이콘·문구로 구분
- [ ] 간격은 8px 스케일 준수
- [ ] 모든 상호작용 요소 44×44px 이상

### 개발
- [ ] Pretendard GOV 폰트 정상 로드 확인 (fallback 미노출)
- [ ] `--color-*` CSS 변수로 컬러 하드코딩 제거
- [ ] `aria-live`, `aria-pressed`, `role="radiogroup"` 등 채팅/선택 컴포넌트 ARIA 속성 적용
- [ ] `:focus-visible` 스타일 제거되지 않았는지 확인
- [ ] `prefers-reduced-motion` 대응

### 접근성 검증
- [ ] axe DevTools / Lighthouse 접근성 90+ 통과
- [ ] 색상 대비율 WebAIM Contrast Checker로 재검증 (특히 Muted 계열 사용처)
