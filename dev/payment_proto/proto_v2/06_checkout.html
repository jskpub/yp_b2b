⚠️
개발 착수 전 확인 필요 — PG 복합결제 지원 여부 기존 영풍문고 PG에서 단일 주문에 2개 결제주체(회사/직원)를 동시 처리하는 기능 자체의 지원 여부는 별도 확인이 필요합니다 (PG사는 기존과 동일 확정, 복합결제 기능 지원은 미확정).
🔧 프로토타입 데모 — 결제 결과 시나리오 미리보기( — 실제 화면에는 노출되지 않음)
  • - 약관 동의 체크박스를 선택해야 하단 [결제하기] 버튼이 활성화됨
  • - [결제하기] 클릭 → "OO원을 결제하시겠습니까?" 확인 팝업
  • - 팝업에서 [결제] 클릭 → "결제 진행 중입니다…" 로딩 팝업(약 1.2초 대기)
  • - 아래 시나리오가 정상 결제 성공이면 → "결제가 완료되었습니다" 팝업 → [주문완료 보기] 클릭 시 07_order-complete.html로 이동
  • - 시나리오를 실패 계열 5종 중 하나로 바꾸면 → "결제에 실패했습니다" 팝업(사유 표시) → [다시 시도] 클릭 시 성공 팝업으로 전환, [닫기] 클릭 시 결제 화면으로 복귀
  • - 토스 페이먼츠 테스트 api 일부 반영(UI 확인용)
실제 화면에는 없는 컨트롤입니다. 아래에서 시나리오를 선택하고 "결제하기"를 눌러보세요.
